Disable Smart App Control + SmartScreen

Windows 11 · Local account · Batch / Rust apps

Why this is needed
Smart App Control (SAC) locks the normal SmartScreen setting “Check apps and files”. When SAC is active, Windows blocks unsigned / unrecognized batch files and often pushes you toward the Microsoft Store. This is especially annoying when you launch Rust apps (or any tools) via .bat / .cmd files all day.

1. Force Smart App Control Off (Registry)

Use this when the UI toggle is greyed out or refuses to switch to Off.

  1. 1 Optional but recommended: create a restore point (search “Create a restore point” → Create).
  2. 2 Press Win + R, type regedit, press Enter. Click Yes on the UAC prompt.
  3. 3 Navigate to this exact path:
    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy
  4. 4 In the right pane look for the value VerifiedAndReputablePolicyState.
    • If it exists → double-click it.
    • If it does not exist → right-click empty space → New → DWORD (32-bit) Value → name it exactly VerifiedAndReputablePolicyState.
  5. 5 Set the value data to 0 and click OK.
    0 = Off   |   1 = On   |   2 = Evaluation
  6. 6 Close Registry Editor. A reboot is usually not required — the change often takes effect immediately. If the SmartScreen options stay locked, reboot once.
After this, open Windows Security → App & browser control → Smart App Control settings. It should now show Off (or at least no longer lock the other settings).

2. Turn off “Check apps and files”

  1. Open Windows Security.
  2. Go to App & browser control.
  3. Click Reputation-based protection settings.
  4. Turn Off “Check apps and files”.
  5. (Optional) Also turn off “Potentially unwanted app blocking”.

3. Unblock your batch files

Even after the above, individual files that were previously blocked may still carry the “Mark of the Web”.

One file at a time

  • Right-click the .bat / .cmd → Properties.
  • At the bottom of the General tab, check Unblock → Apply → OK.

Whole folder (PowerShell)

Open PowerShell in the folder that contains your batch files and run:

Get-ChildItem -Path . -Recurse -Include *.bat,*.cmd,*.ps1 | Unblock-File

4. Extra setting that helps

Stop Windows from pushing the Store for non-Store apps:

  • Settings → Apps → Advanced app settings
  • (or search for “Choose where to get apps”)
  • Set it to Anywhere

Quick reference – Registry one-liner

You can also run this in an elevated Command Prompt or PowerShell:

reg add "HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy" /v VerifiedAndReputablePolicyState /t REG_DWORD /d 0 /f
Note about Windows updates
Major cumulative updates sometimes re-enable Smart App Control or SmartScreen. If batch files suddenly start getting blocked again, re-check the registry value and the “Check apps and files” toggle. Your O&O ShutUp10 / Win11Debloat settings can also help keep related telemetry and suggestions down, but they do not fully control SAC.
Saved for local reference · Works on Windows 11 (24H2 / 25H2 era) · Local account friendly
Primary method: registry force-off of Smart App Control so the normal SmartScreen toggles become usable again.
